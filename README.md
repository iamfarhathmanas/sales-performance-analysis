# Sales Performance Analysis

An end-to-end SQL-based sales analytics portfolio project focused on revenue, profit, product, regional and channel performance.

## Tools
- SQL
- Python (Pandas, Matplotlib)

## Business Questions
- What are total revenue, profit and profit margin?
- Which products generate the most revenue and profit?
- Which regions perform best?
- How does revenue change month to month?
- Which channels have stronger margins?

## Workflow
1. Validate and clean the dataset.
2. Explore the data with Python.
3. Answer business questions with SQL.
4. Translate findings into business insights.

## Repository Structure
- `data/` — generated practice dataset
- `sql/` — SQL analysis queries
- `python/` — exploratory analysis script

## Dataset Note
This portfolio project uses generated practice data. It is not employer/client data.
