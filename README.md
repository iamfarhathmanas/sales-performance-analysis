# Sales Performance Analysis — SQL Portfolio Project

## Overview
An end-to-end sales analytics project focused on turning transactional data into business insights using SQL and Python.

## Objective
Evaluate revenue, profitability, product performance, regional contribution, sales channels, and monthly trends.

## Business Questions
- What are total revenue, total profit, and profit margin?
- Which products drive the most revenue and profit?
- Which regions contribute the most value?
- How does performance change month to month?
- Which sales channels generate stronger margins?

## Toolkit
**SQL** • **Python** • **Pandas** • **Matplotlib** • Data Cleaning • Exploratory Data Analysis • Business Analysis

## Workflow
1. Inspect and validate the dataset.
2. Prepare the data for analysis.
3. Answer business questions with SQL.
4. Use Python for exploratory analysis and validation.
5. Translate findings into business-focused insights.
